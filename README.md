## Overview

Personal Portfolio is a responsive web application designed to establish my professional presence as a Software Developer.

It brings together my development background, technical capabilities, selected projects, and contact information in an interactive digital experience.

The project combines modern frontend technologies, animation libraries, and 3D rendering tools to create an engaging and visually rich interface.

## Tech Stack

| Category            | Technologies                                |
| ------------------- | ------------------------------------------- |
| Framework           | Next.js 15                                  |
| UI Library          | React 18                                    |
| Language            | TypeScript                                  |
| Styling             | Tailwind CSS                                |
| Animation           | GSAP, Framer Motion, Anime.js, React Spring |

| UI Components       | Lucide React, React Icons                   |

## Getting Started

### Prerequisites

- Node.js
- pnpm
- Git

### Installation

**1. Clone the repository**

```bash
git clone git@github.com:Timothy-Attah/Personal-Portfolio.git
```

**2. Navigate into the project directory**

```bash
cd Personal-Portfolio
```

**3. Install dependencies**

```bash
pnpm install
```

**4. Start the development server**

```bash
pnpm dev
```

**5. Open your browser**

Visit `http://localhost:3000`.

## Available Scripts

| Command      | Description              |
| ------------ | ------------------------ |
| `pnpm dev`   | Start development server |
| `pnpm build` | Build for production     |
| `pnpm start` | Start production server  |
| `pnpm lint`  | Run ESLint               |

## Environment Configuration

If your local configuration requires environment variables, create a `.env.local` file in the root directory and add the required values.

Never commit private credentials, API secrets, or environment files to the repository.
